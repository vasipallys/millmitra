🔄 Verification Workflow:

1User Initiates Edit

  • User clicks "Edit" on farmer information
  • System opens edit dialog with current data
  • User must provide reason for edit
  • Alert shows that changes require approval

2System Processes Request

  • System compares original vs. proposed changes
  • Identifies which fields are being modified
  • Determines priority level (high/medium/low)
  • Checks if auto-approval is possible

3Auto-Approval Logic

  • Minor Changes: Email, address, farming experience (auto-approved)
  • Critical Changes: Name, phone, Aadhar, bank details (requires approval)
  • Bulk Changes: Multiple fields (requires approval)
  • Immediate Application: Auto-approved changes applied instantly

4Approval Process

  • Pending requests appear in "Edit Requests" section
  • Administrators can review proposed changes
  • Side-by-side comparison of old vs. new values
  • Approve with optional comments or reject with required reason

5Change Application

  • Approved changes are immediately applied to farmer record
  • Rejected changes remain in history for reference
  • All actions are logged with timestamps and user details
  • Notifications sent to relevant parties
