🔧 Troubleshooting:

If Backend Fails to Start:

Issue 1: Port Already in Use

# Check what's using port 5000 netstat -ano | findstr :5000 # Kill the process if needed taskkill /PID [PID_NUMBER] /F # Or use a different port python app.py --port=5001

Issue 2: Missing Dependencies

# Install all requirements pip install -r requirements.txt # Or install specific missing packages pip install flask flask-cors redis python-dotenv

Issue 3: Python Path Issues

# Make sure you're in the right directory cd D:\GenAi\ricemill\backend # Check Python version python --version # Try with python3 if needed python3 app.py
