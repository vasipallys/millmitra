🧪 Manual PWA Testing Guide

Step-by-step guide to test your Smart Rice Mill ERP Progressive Web App

🚀 Step 1: Start Backend Server

Open a new terminal/command prompt and run:

C:\> cd D:\GenAi\ricemill\backend D:\GenAi\ricemill\backend> python app.py

✅ Expected Output:

  • □ No import errors
  • □ Database connection successful
  • □ Server running on http://localhost:5000
  • □ "Running on http://127.0.0.1:5000" message

Test Backend: Open browser and go to http://localhost:5000/api/health

Expected: Should return JSON health status

📱 Step 2: Start Frontend Server

Open another terminal/command prompt and run:

C:\> cd D:\GenAi\ricemill\frontend D:\GenAi\ricemill\frontend> npm run dev

✅ Expected Output:

  • □ Vite dev server starts
  • □ No compilation errors
  • □ "Local: http://localhost:3000" message
  • □ Browser opens automatically (optional)

🌐 Step 3: Open Application

Open Chrome or Edge browser and navigate to:

http://localhost:3000

✅ What You Should See:

  • □ Rice Mill ERP application loads
  • □ Login page or dashboard appears
  • □ No JavaScript errors in console (F12)
  • □ PWA install prompt may appear

🔍 Step 4: Check PWA Manifest

Open Developer Tools (F12) and check PWA readiness:

  1. Press F12 to open Developer Tools
  2. Click on "Application" tab
  3. In the left sidebar, click "Manifest"
📱 You should see the Smart Rice Mill ERP manifest with:
• Name: "Smart Rice Mill ERP"
• Short Name: "Smart Mill"
• Icons: 3 icons (favicon.svg, logo192.svg, logo512.svg)
• Display: "standalone"
• Theme Color: "#1976d2"

✅ Manifest Verification:

  • □ Manifest loads without errors
  • □ All 3 icons are present and load
  • □ App shortcuts are defined
  • □ No manifest warnings

🔄 Step 5: Check Service Worker

In the same Developer Tools Application tab:

  1. Click "Service Workers" in the left sidebar
  2. You should see the Smart Mill service worker

✅ Service Worker Status:

  • □ Service Worker is registered
  • □ Status shows "activated and running"
  • □ Source: /sw.js
  • □ No registration errors

💾 Step 6: Test Caching

Check if resources are being cached:

  1. In Developer Tools, click "Storage" in left sidebar
  2. Expand "Cache Storage"
  3. You should see "smart-mill-v1.0.0" cache
  4. Click on it to see cached resources

✅ Cache Verification:

  • □ Cache storage exists
  • □ Static files are cached (JS, CSS)
  • □ Manifest and icons are cached
  • □ Service worker file is cached

📡 Step 7: Test Offline Functionality

Test the app's offline capabilities:

  1. In Developer Tools, go to "Network" tab
  2. Check the "Offline" checkbox
  3. Refresh the page (Ctrl+R or F5)

✅ Offline Tests:

  • □ Page still loads when offline
  • □ Cached pages are accessible
  • □ Offline indicator appears (if implemented)
  • □ Navigate to /offline.html works

Don't forget to uncheck "Offline" when done testing!

📲 Step 8: Test PWA Installation

Test installing the app:

Desktop Installation:

  1. Look for an install icon in the browser address bar
  2. Click the install icon or use browser menu → "Install Smart Mill"
  3. Follow the installation prompts

Mobile Installation (if testing on mobile):

  1. Open the app in mobile browser
  2. Look for "Add to Home Screen" option
  3. Add the app to your home screen

✅ Installation Tests:

  • □ Install prompt appears
  • □ Installation completes successfully
  • □ App opens in standalone window
  • □ App appears in Start Menu/Applications
  • □ App shortcuts work (right-click on icon)

🔔 Step 9: Test PWA Components

Test the React PWA components:

✅ Component Tests:

  • □ PWA install prompt component appears
  • □ Install button works in the prompt
  • □ Offline status indicator works
  • □ No console errors related to PWA components

⚡ Step 10: Performance Testing

Test PWA performance:

  1. In Developer Tools, go to "Lighthouse" tab
  2. Click "Generate report"
  3. Select "Progressive Web App" category
  4. Run the audit

✅ Performance Targets:

  • □ PWA Score: 90+ (Excellent)
  • □ Performance: 80+ (Good)
  • □ All PWA criteria met
  • □ No critical PWA issues

🎉 PWA Testing Complete!

If all tests pass, your Progressive Web App is working perfectly!

🐛 Troubleshooting

Common Issues and Solutions:

  • Service Worker not registering: Check console for errors, clear browser cache
  • Icons not loading: Verify icon files exist in frontend/public/
  • Install prompt not showing: Check manifest validity, try incognito mode
  • Offline not working: Ensure service worker is active and caching
  • Console errors: Check import statements and file paths

Quick Fixes:

// Clear browser cache and data // Chrome: Settings → Privacy → Clear browsing data // Force refresh (bypass cache) Ctrl + Shift + R (Windows) Cmd + Shift + R (Mac) // Check service worker in console navigator.serviceWorker.getRegistrations().then(console.log)
