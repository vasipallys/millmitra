🔧 Formik Initialization Error - FIXED!

The "Cannot access 'formik' before initialization" error has been resolved!

❌ Original Error:

ReferenceError: Cannot access 'formik' before initialization
at RecordProcurementDialog (RecordProcurementDialog.jsx:40:19)

The error occurred because useQuery hooks were trying to access formik.values.farmer_id before the formik object was declared.

🔍 Root Cause Analysis:

JavaScript Hoisting Issue

In the RecordProcurementDialog component:

  1. Line 40: useQuery(['contracts', formik.values.farmer_id], ...)
  2. Line 48: const formik = useFormik({...})

The useQuery was trying to access formik before it was declared, causing a ReferenceError.

✅ Solution Applied:

✅ Fix 1: Introduced State Variable
Added const [selectedFarmerId, setSelectedFarmerId] = useState(''); to track farmer selection independently.
✅ Fix 2: Updated useQuery Dependencies
Changed useQuery(['contracts', formik.values.farmer_id], ...) to useQuery(['contracts', selectedFarmerId], ...)
✅ Fix 3: Synchronized State Updates
Updated the farmer selection onChange handler to update both formik and the state variable:
const farmerId = newValue?.id || ''; formik.setFieldValue('farmer_id', farmerId); setSelectedFarmerId(farmerId);
✅ Fix 4: Added Cleanup Effect
Added useEffect to reset selectedFarmerId when dialog closes:
useEffect(() => { if (!open) { setSelectedFarmerId(''); } }, [open]);
