This error occurred when the dashboard service tried to access the overall_score attribute on QualityTest objects, but this attribute doesn't exist in the model.

🔍 Root Cause Analysis:

Model Attribute Mismatch

The dashboard service was trying to access t.overall_score but the QualityTest model doesn't have this attribute. Instead, it has a calculate_quality_score() method that computes the quality score dynamically.

# What the dashboard service was trying to do: avg_quality = sum(t.overall_score or 0 for t in recent_tests) / len(recent_tests) # But QualityTest model has: def calculate_quality_score(self): """Calculate overall quality score""" # ... calculation logic

✅ Solution Applied:

✅ Fixed Method Call
Changed the dashboard service to use the correct method:
# Before (problematic) avg_quality = sum(t.overall_score or 0 for t in recent_tests) / len(recent_tests) # After (fixed) avg_quality = sum(t.calculate_quality_score() or 0 for t in recent_tests) / len(recent_tests)

Now the dashboard service calls the calculate_quality_score() method instead of trying to access a non-existent attribute.
